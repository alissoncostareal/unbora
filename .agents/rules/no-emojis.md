# Regra: Proibição Estrita de Emojis

Esta regra é obrigatória e deve ser respeitada em qualquer alteração ou interação:

1. **Zero Emojis**: É estritamente proibido o uso de qualquer caractere unicode de emoji em todo o ecossistema Unbora.
2. **Abrangência**:
   - Código TypeScript, JavaScript, HTML, CSS, SQL e Java.
   - Componentes visuais em `frontend/`, `business/`, `admin/` e `mobile/`.
   - Mensagens da API, logs do backend, respostas HTTP e DTOs.
   - Textos de botões, modais, cabeçalhos, menus e badges.
   - Respostas do assistente nas conversas.
3. **Padrão Aceito**: Usar apenas ícones **SVG vetoriais** ou tipografia editorial limpa.
